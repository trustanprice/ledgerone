# AGENTS.md — reports/

Fleet: [../AGENTS.md](../AGENTS.md)

## Purpose

Output of `src/generate_report.py`, regenerated by `make report` (or as
part of `make all`). Unlike `data/`, these outputs **are** committed —
they're the concrete "a business user could look at this" evidence the
pipeline produces, not just intermediate state.

- `monthly_revenue_and_refund_rate.csv` — export of the mart of the same
  name (tracked despite the repo's blanket `*.csv` ignore — see the
  `!reports/*.csv` exception in `.gitignore`).
- `monthly_revenue_trend.png`, `refund_rate_trend.png`,
  `avg_transaction_value_trend.png` — charts built with matplotlib from the
  `main_marts.*` reporting tables.

## Conventions

- Everything in this folder except `AGENTS.md` itself is fully regenerable
  from `main_marts.*` — if it looks stale after changing a reporting mart,
  just re-run `make report`, don't hand-edit. `make clean` only removes the
  generated `*.png`/`*.csv`, never `AGENTS.md`.
- `generate_report.py` only reads from `dbt`'s reporting marts, never from
  staging or core directly — if a new chart needs a column that doesn't
  exist yet, add it to the relevant mart in `dbt/models/marts/reporting/`
  first.
